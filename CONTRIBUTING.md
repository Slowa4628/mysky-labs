# Contributing

Issues and pull requests are welcome for documentation, OpenAPI clarity and public examples.

Before opening a pull request:

1. Do not include API keys, credentials, personal location history, server addresses or private engine source.
2. Keep examples compatible with the published OpenAPI contract.
3. Explain which endpoint, parameter or response is affected.
4. Do not claim an engine is verified or more accurate than another engine without a published methodology and measurements.

New public code belongs in `packages/<name>/` and requires a separate discussion of license, versioning, tests and maintenance scope.
